# Installing a Seconds Ethernet Port on the Server
## Commands to install ethernet drivers
### Locally From the Laptop
Download driver files from [intel](https://www.intel.com/content/www/us/en/download/15084/intel-ethernet-adapter-complete-driver-pack.html) and unzip the package. 
Locate the file `ixgbe-X.X.X.tar.gz` (on Windows this might appear without the second file extension) under `/PROXGB/LINUX/` and then:
```shell
scp ixgbe-6.4.4.tar.gz root@192.168.10.10:/root/Downloads
```
### On The Server Machine
Connect to the `root` user and then:
Following the installation guide at the [driver's repo](https://github.com/intel/ethernet-linux-ixgbe#:~:text=To%20manually%20build%20the%20driver%0A%2D%2D%2D%2D%2D%2D%2D%2D%2D%2D%2D%2D%2D%2D%2D%2D%2D%2D%2D%2D%2D%2D%2D%2D%2D%2D%2D%2D):
```shell
tar zxf ixgbe-X.X.X.tar.gz
cd ixgbe-X.X.X
```
If this is the first thing you do on the machine you would need to run:
```shell
apt install build-essential pve-headers
```
And then continue with the installation:
```shell
make install 
modprobe ixgbe
```
Then to find the name of your network card use:
```shell
ip addr show
```

(MAC addresses have been changed for security :))
Which means my router already found and allocated an address to the interface `nic0` - `192.168.10.10/24`, and that `nic1` is the second interface which we want to define now.
```shell
ip addr add 192.168.10.11/24 dev nic1
```
